## 👨‍💻 About Me

I'm a **Data Engineer** passionate about building reliable data platforms, scalable pipelines, and production-ready AI applications.

My experience spans distributed data processing, analytical database optimization, workflow orchestration, cloud-native infrastructure, MLOps, and agentic AI. I enjoy solving complex engineering problems and turning data and machine learning concepts into practical systems.

- ⚙️ Building and optimizing data pipelines and analytical platforms at billion-record scale.
- 🚀 Modernizing data infrastructure with Apache Airflow, ClickHouse, Kubernetes, and CI/CD.
- 🤖 Developing machine learning pipelines, real-time inference services, and AI agents.
- 🔎 Exploring LLM applications, semantic layers, and Model Context Protocol (MCP).
- 📈 Focused on reliability, performance, observability, and maintainable engineering.

> **My philosophy:** Build reliable data systems. Turn complexity into clarity. Ship solutions that matter.
